# tools — таблицы истинности и схема из таблицы

- `gen_pla.py` — генератор таблиц истинности (PLA) для сложения, вычитания, умножения,
  умножения-со-сложением любой разрядности, с насыщением/обрезкой/точным результатом.
  `python3 gen_pla.py --help`.
- `make_table_netlist.sh` — строит схему T3 (сложение с насыщением 9+8 → 8) прямо из
  таблицы истинности: gen_pla.py → ABC → Verilog. Её использует вариант `table`.
- `abc.rc` — стандартные сокращения команд ABC (resyn2, compress2rs).

Чтобы проверить свой метод логического синтеза: подайте ему `out/T3.pla` или `out/T2.pla`,
вставьте полученный модуль Verilog вместо `mac_t3_table` в `variants/mac_unit_table.v`
и сравните: `python3 scripts/synth_local.py single table` (секунды) или полный прогон на GitHub.

Опыт 13.10.2026 (ABC, синтез из таблицы против записи на Verilog, число вентилей И):
| функция | из таблицы | из Verilog |
|---|---|---|
| T3: сложение с насыщением | 79 | 69 |
| T2: умножение 8×8 с насыщением до 9 бит | 3 668 | ≈ 490 |
Умножитель из таблицы стандартными средствами в ~7 раз больше: без разложения на части
табличный путь для умножения не работает.
